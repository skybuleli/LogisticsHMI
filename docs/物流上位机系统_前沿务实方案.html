SkiaSharp 4.x：2D 绘图能力质的飞跃
v4 版本引入了大量对工业上位机直接可用的新特性——无需依赖任何外部绘图工具
🔤
OpenType 可变字体

SkiaSharp 4 + HarfBuzzSharp 完整支持 OpenType Variable Font。可在运行时通过轴参数（weight/width/slant/optical size）连续调节字体形态，而不是只能选择固定的 Bold/Light。

上位机用途：设备编号标签自动缩放到合适粗细；状态文字从"正常"的纤细到"紧急报警"的粗重，仅用一套字体即可动态变化。

可变字体HarfBuzzSharp
🎨
色彩字体调色板 (CPAL)

支持 OpenType CPAL 调色板——可在运行时切换彩色字体的配色方案，甚至覆盖单个字形的颜色。

上位机用途：用彩色图标字体（如 Material Symbols / Noto Color Emoji）直接渲染设备状态指示灯——绿色运行、黄色待机、红色故障，一套字体解决所有状态图标。不再需要分别准备多套 PNG/SVG 图标。

彩色图标字体状态指示灯
🖼️
图像处理增强

• mipmap 锐化默认开启：缩略图、小图标自动更清晰锐利

• Exif 自动旋转：图像编解码器自动识别并修正照片方向

• 色彩准确性提升：Rec.709 / HLG / PQ 传递函数修正，颜色更精准

上位机用途：库区缩略图更清晰；相机拍照的设备巡检图自动正确方向；仪表盘颜色显示更准确。

自动锐化Exif色彩精准
🔧
SKPathBuilder + 不可变路径

SKPathBuilder 是全新的路径构建 API，更符合现代 .NET 习惯。底层 SKPath 变为不可变——线程安全、可缓存复用。

上位机用途：设备外形轮廓（堆垛机、AGV 车体、输送线箭头）用 SKPathBuilder 构建后缓存为不可变路径，多线程渲染时安全共享，性能大幅提升。一台设备只需构建一次，之后所有视图复用。

线程安全路径缓存
⚡
GPU 后端：Metal / Vulkan

SkiaSharp 4 继续增强 GPU 后端支持：OpenGL / Metal (macOS) / Vulkan (Linux/Windows)。超大位图自动分片适配 GPU 纹理上限。

上位机用途：Mac 上通过 Metal 后端获得最佳渲染性能；复杂库区布局（数千个货位）使用 GPU 渲染流畅无卡顿；Vulkan 后端在 Linux 工控机上提供硬件加速。

事件驱动架构：MediatR 免费替代方案
MediatR v12+ 和 MassTransit v9+ 已转向商业许可——这些 MIT 开源替代品可以直接替换
库许可特性适用场景推荐度
Wolverine MIT 全能型：Mediator + 消息总线 + 后台任务 + Saga + Outbox；源码生成器驱动；支持多种传输（RabbitMQ/Kafka/Azure）；重试/调度/死信队列 需要完整事件驱动架构的中大型项目 🏆 首选
Concordia MIT 轻量级：C# Source Generator 编译时注册；API 几乎与 MediatR 相同；支持 Request/Response + Pub/Sub；极高性能 从 MediatR 迁移、轻量事件驱动 推荐
ModernMediator MIT MediatR 风格 + Pub/Sub；NativeAOT 友好；内置 UI 调度器（Avalonia/WPF/WinForms）；弱引用订阅 桌面应用内的 MVP 模式通信 可选
ConduitR MIT 轻量 Mediator；热路径缓存 + 最小分配；内置验证、ASP.NET、弹性策略扩展 Web API 项目中的 CQRS 可选
以上全部 MIT 许可，永久免费，可用于商业闭源项目
🔄
推荐：Wolverine（进程内事件）

对上位机最合适。不仅替代 MediatR 的进程内消息分发，还内置了本地队列、重试策略、计划任务、死信处理——非常适合工业场景中"发送指令→等待确认→超时重试→记录失败"这类可靠性要求高的通信模式。

dotnet add package WolverineFx

⚡
轻量替代：直接注入 + Channels

如果团队不想引入任何 Mediator 库，上位机完全可以用更简单的方式实现事件驱动：

• C# event / Action 委托 — 最简单的事件通知

• System.Threading.Channels — 高性能异步事件管道

• 直接 DI 注入服务 — 调用应用层服务即可

上位机是单体桌面应用，不一定需要 Mediator 模式。

📌 务实建议：对于上位机这种单体桌面应用，最简单的方案往往最好。起步阶段直接用 DI 注入服务 + C# event。当模块间通信变得复杂（如报警模块需要同时通知 UI、日志、短信三个消费者），再引入 Wolverine。这样既避免了过度设计，又保留了升级路径。

2.3Modbus RTU 驱动基于 System.IO.Ports 实现串口通信。支持 9600/19200/38400/115200 波特率、8N1 数据位、无校验/奇校验/偶校验。CRC16 校验计算和验证。自动检测串口列表。ModbusRtuDriver

2.6MQTT 驱动基于 MQTTnet 5.0 实现。支持 QoS 0/1/2、Will Message、TLS 加密。主题设计规范（设备状态/报警/心跳）。自动重连与离线消息缓存。MqttDriver
2.7连接池管理器统一管理所有设备驱动的连接。复用 TCP 连接避免频繁建链。连接数上限控制、空闲连接回收。连接健康检查（定时心跳）。ConnectionPool 类
2.8心跳与自动重连每个驱动独立的定时心跳（默认 5s 间隔）。连续 3 次心跳失败触发重连。指数退避重试策略（1s → 2s → 4s → 8s → 最大 30s）。重连成功/失败事件通知上层。心跳管理器、重连策略
2.9数据缓存层设备寄存器数据本地缓存（MemoryCache），设置 TTL 过期时间。读取时优先查缓存，写操作后立即更新缓存。减少对 PLC 的重复读取压力。DeviceDataCache
2.10模拟设备驱动开发 VirtualDevice 模拟器：模拟堆垛机（支持前进/后退/升降/货叉动作）、模拟输送线（速度/方向/货物检测）、模拟传感器（温度/振动/电流随机波动）。用于无真实硬件时的开发和演示。VirtualDeviceSimulator

#具体任务说明
7.1单元测试xUnit + Moq + AutoFixture。覆盖：通信协议解析/组包（Modbus 帧 CRC 校验、S7 PDU 解析）、任务调度算法（A* 路径输出验证）、报警规则引擎（各种阈值组合）、状态机转换逻辑。目标：领域层覆盖率 ≥ 80%。
7.2集成测试TestContainers 启动 PostgreSQL/Redis/RabbitMQ 容器。完整流程测试：模拟 WMS 下发任务 → 任务接收 → 拆分 → 分配设备 → 模拟设备执行 → 状态更新 → 结果回调。报警触发到通知全链路测试。数据库迁移测试。
7.3性能基准测试BenchmarkDotNet 测试：Modbus 帧解析速度（target < 50μs/帧）、数据管道吞吐量（target > 50K msg/s）、1000 台设备并发轮询延迟（target < 100ms/轮）、UI 渲染帧率（target ≥ 60 FPS @1080p）、NativeAOT 冷启动时间（target < 2s）。
7.4压力与稳定性测试72 小时连续运行（模拟设备持续发送数据）。内存泄漏检测（dotnet-counters / PerfView）。CPU 使用率监控（稳态 target < 30%）。模拟网络中断/恢复、PLC 故障/恢复的异常场景。
7.5现场联调部署到真实工控机环境。对接真实 PLC（至少西门子 S7-1200 + Modbus TCP 设备）。验证实际通信延迟和稳定性。根据现场反馈调整 UI 布局、报警阈值、操作流程。
7.6NativeAOT 编译发布配置 .csproj：PublishAot=true、TrimMode=full。处理反射和动态加载的 AOT 兼容性问题（RD.xml 配置）。单文件发布（IncludeNativeLibrariesForSelfExtract）。目标：Windows x64 单 exe < 80MB。
7.7Docker 容器化编写 Dockerfile（基于 .NET chiseled 镜像）。Docker Compose 编排（上位机 + PostgreSQL + Redis + TDengine + RabbitMQ）。支持环境变量注入配置。容器健康检查。
7.8CI/CD 流水线GitHub Actions：Push → Build → Test → Publish Artifact。自动版本号生成（GitVersion）。Release 分支触发自动打包（Windows .exe + Linux AppImage + Docker Image）。自动发布到 GitHub Release。
7.9用户文档安装部署手册（环境要求/安装步骤/初始配置）。操作手册（各功能模块使用说明、截图标注）。运维手册（日志查看、备份恢复、常见故障排查）。API 文档（Swagger 导出）。

✅ Phase 7 验收标准：单元测试覆盖率 ≥ 80%。72 小时稳定性测试无内存泄漏。NativeAOT 编译成功且启动 < 2s。能通过 Docker Compose 一键部署完整环境。用户文档完整可交付。
